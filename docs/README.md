# CafeOS

CafeOS is a modern Restaurant Operating System designed for cafés, restaurants, and food businesses.

It is built with an **offline-first philosophy** and modular architecture so businesses can run without internet while still benefiting from cloud features.

---

# Core Features

- POS Order Management
- Table Management
- Kitchen Workflow
- Billing & Payments
- Role Based Access Control
- Shift Management
- Reports
- Modular Plugin System (future)

---

# Technology Stack

Backend:
- Laravel API
- MySQL
- JWT Authentication

Frontend:
- Electron POS App
- HTML / JS / CSS

---

# Architecture Philosophy

CafeOS is built with:

- Offline-first POS
- Modular system
- Theme engine
- Plugin architecture
- Cloud optional
